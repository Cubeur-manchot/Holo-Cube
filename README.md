# Holo-Cube
Tool to display cube images given one or many move sequences.

## Technical information
JavaScript code, embeddable in web pages or Discord bots.
JSON I/O : either return an SVG image or an error object.

## Options/Customization
- all cubes from 1x1x1 to NxNxN, with no strict limit to N
- different views
  - plan : U face, for last layer algs
  - isometric : U, F and R faces, for F2L algs for example
- full color scheme customization
- image size, puzzle size
- logs location
