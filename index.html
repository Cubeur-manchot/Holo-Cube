Holo-Cube

What is Holo-Cube ?

Holo-Cube is a JavaScript library to build images of NxNxN cubes. These are already using it:

  • Les Algos d'un Manchot (web page, frontend)
  • AlgBot (NodeJS bot, backend)
GitHub repository

Try it yourself

Play with it on the Try It Yourself page.

Options

All cubes from 1x1x1 to 34x34x34 can be displayed. Although 34x34x34 should be enough, higher is still possible as there is no strict limitation. AlgBot has shown an image of a 100x100x100 cube.

Apart from the cube size, all other options have default values, which could be overriden if desired. Try it yourself to see how options must be specified.

  • Cube options: Stage (OLL, F2L, Cross, COLL, VLS, CMLL, ...), View (Plan, Isometric), Color scheme
  • Drawing options: Image dimensions, Puzzle dimensions
  • Logger: Mode (Console, HTML tag, None), In Output or not, Verbosity

How to use Holo-Cube in a website ?

Import the library

Option 1: ES module bundle

import { Runner } from "https://cubeur-manchot.github.io/Holo-Cube/bundles/holo-cube-algorithm.module.js";

Option 2: classic bundle

<script src="https://cubeur-manchot.github.io/Holo-Cube/bundles/holo-cube-algorithm.classic.js"></script>

Instanciate a Run object

const runner = new Runner({
    puzzle: {
        fullName: "cube3x3x3"
    },
    moveSequenceList: algList
});

Run on one or multiple algorithms

// single alg
const result = runner.run("M2 E2 S2");
// multiple algs
const resultMultiple = runner.run(["R U R' U'", "R' F R F'"]);

Use the result

// single alg
document.querySelector("#imageContainer").appendChild(result.svg); // adjust to your own HTML
// multiple algs
const imageContainers = document.querySelectorAll(".imageContainer");
resultMultiple.results.forEach((svg, index) => imageContainer[index].appendChild(svg)); // adjust to your own HTML
